Place your profile photograph here as `profile.jpg`:

`frontend/src/assets/profile.jpg`

The login page, sidebar, and signed-in account header use this image. A square photograph
works best; it is cropped to a circle. Until it is added, a neutral profile icon is
shown. This is a shared site image, not a separate photograph for each account.
Vite picks it up during development; rebuild the frontend after adding or changing
the image for a production deployment.
